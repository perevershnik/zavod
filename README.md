# Сільпо: Darkstore Simulator

Готовая мини-игра для GitHub Pages.

## Как запустить
1. Создай новый репозиторий на GitHub.
2. Загрузи сюда `index.html`, `style.css`, `script.js` и папку `assets`.
3. Открой Settings → Pages.
4. В Source выбери `Deploy from a branch`.
5. Branch: `main`, folder: `/root`.
6. Сохрани — GitHub выдаст ссылку на сайт.

## Как заменить фотографии
Положи свои фото в папку `assets`:

- `vlad.jpg`
- `zhenya.jpg`
- `alina.jpg`
- `dima.jpg`

Или измени имена/пути в массиве `workers` в начале файла `script.js`.

## Как добавить коллегу
Добавь ещё одну строку в массив `workers`:

```js
{ id: 5, name: 'Имя', role: 'Комплектувальник', photo: 'assets/photo.jpg', x: .5, y: .5 },
```
