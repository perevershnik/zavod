# Flying Colleagues — mobile version

Сайт сделан специально под телефон.

## Что делает
- круглые фотографии коллег постоянно двигаются по экрану;
- сталкиваются и отскакивают друг от друга;
- фото можно немного толкать пальцем;
- при обычном нажатии появляется персональная фраза;
- есть кнопка случайной мотивации;
- есть кнопка перемешивания/ускорения.

## Как добавить свои фотографии
Положи фото в папку `assets`:

- `vlad.jpg`
- `zhenya.jpg`
- `alina.jpg`
- `dima.jpg`
- `sasha.jpg`

## Как изменить людей и фразы
Открой `script.js`.
В самом начале находится массив `people`.

Пример:

```js
{
  name: "Влад",
  photo: "assets/vlad.jpg",
  quote: "Твоя фраза"
}
```

Можно удалить человека, добавить нового или изменить фразу.

## GitHub Pages
Загрузи в корень репозитория:
- index.html
- style.css
- script.js
- папку assets

После этого:
Settings → Pages → Deploy from a branch → main → /(root)
